# 一生一芯学习记录

这个仓库保存我在“一生一芯”预学习阶段编写的代码、练习和学习笔记。它是个人学习记录，不是课程官方仓库。

| 目录 | 内容 |
|---|---|
| [`f`](f) | 数字电路与处理器相关练习 |
| [`e/e1`](e/e1) | Verilog 练习与学习记录 |
| [`e/e2`](e/e2) | Linux C 基础练习与学习记录 |
| [`e/e3/missing-semester`](e/e3/missing-semester) | Linux 工具课程练习 |

E3 的范围参照[一生一芯 26.07 讲义](https://ysyx.oscc.cc/docs/2607/e/3.html)。其中部分 C 示例基于 Zed A. Shaw 的 *Learn C the Hard Way*，个人修改与扩展和教材示例放在一起保存；具体库的说明见 [`lcthw/README.md`](e/e3/c_advanced/lcthw/README.md)。

仓库只保存源码、练习数据和文档，不保存本地编译产物、调试转储或私有配置。C 项目在 Linux/WSL 环境中构建。
