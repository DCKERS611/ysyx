## 1. 目标与时间原则

本计划对应“一生一芯”E4，目标是完成以下部分：

1. 搭建 Verilator RTL 仿真环境，掌握 `Verilog 源码 → C++ 仿真文件 → 可执行文件 → 运行仿真 → 查看波形` 的完整工作流。
2. 用**结构化建模**（实例化 + 连线）编写组合逻辑电路和时序逻辑电路。
3. 借助 NVBoard 虚拟板卡完成 5 个数字电路实验。
4. 用 RTL 实现 sCPU（把 Logisim 设计翻译成 Verilog）。
5. 掌握 DiffTest 验证方法。

时间原则：

- 预计 **12～18 个有效学习日，约 2.5～3.5 周**（按每天 4 小时计）。
- 比 E3 略重：E3 主要是学 C 语言工具链，E4 要同时学**新工具链（Verilator）+ 从电路图写 RTL + 5 个数字电路实验 + 一个处理器实现**。
- 超时顺延，不跳步、不删减。不以“看懂代码/看完讲义”作为完成；每个电路必须能在仿真或 NVBoard 上跑出正确现象。

建议学习比例：阅读/视频 25%，亲手写 RTL 和仿真 60%，复盘 15%。

## 5. 关键规范：不要使用行为建模（E4 最重要的一条）

- [ ] 不写任何 `always` 块（官方 `Reg`/`MuxKey` 模板内部除外）。
- [ ] 用数据流建模（`assign`）和结构化建模（实例化 + 连线）直接描述电路。
- [ ] 用官方触发器模板 `Reg`、选择器模板 `MuxKey` / `MuxKeyWithDefault` 代替手写 `always`。
- [ ] 不用 `negedge`（只用 `posedge`）。
- [ ] 不使用锁存器（Latch）。

**当前进度**：流水灯已用 `Reg` 改写（`light.v` 中无 `always`），并通过与 `always` 版的逐拍等价验证（`CNT_MAX=4`，1000 万拍零差异）。`vsrc/template.v` 里的 `always` 属于官方模板，不算违规。本节五条已满足，`make lint` 无 warning。

自检问题（答不上来就不该用行为建模）：

- 在硬件描述语言中，“执行”的精确含义是什么？
- 是谁在执行 Verilog 的语句？是电路，是综合器，还是其它？
- `if` 条件满足就不执行 `else`，“不执行”到底是什么意思？

（写流水灯时会撞上第三个问题：`if (cnt == 0) led <= ...;` 里的“条件不成立的那一拍”，`led` 的下一状态到底是什么？把这个想清楚，`if` 和选择器的关系就通了。）

### 遗留的小问题

- `bcd.v` 的 `assign seg = en ? ~bcd_out : 8'b0000_0000;`：`en=0` 时输出全 0，在 NVBoard 上是**全段点亮（显示 `8`）**。若想“无输入时熄灭”，应改成 `8'b1111_1111`。下次上板时核对全 0 输入那组的数码管到底显示 `8` 还是 `0`。

### 之后：阶段 D（5 个数字电路实验）

按顺序做，每个实验都要走完“设计 → RTL → 仿真 → 波形 → lint → NVBoard → 解释”七步（见第 6 节）：

1. **实验二　译码器和编码器** —— 第一次大量使用 `MuxKey`：译码器就是“输入当键、输出当数据”的查找表，正好是 `MuxKey` 的形状。
2. **实验三　加法器与 ALU** —— 加法器用 `assign` + 位拼接描述进位链；ALU 用 `MuxKey` 按 `op` 选运算结果（结构上等价于 `always` 里的 `case`）。
3. **实验六　移位寄存器及桶形移位器** —— 移位寄存器 = `Reg` + 位拼接 `assign`；桶形移位器是“分级选择器”的经典结构。
4. **实验七　状态机及键盘输入** —— 状态机 = `Reg` 存 `state` + `MuxKeyWithDefault` 算 `next_state`，正好把 `MuxKey` 用起来；键盘输入可先用按键，再做 PS/2。
5. **实验八　VGA 接口控制器** —— 最难，预留 1.5～2 天。

**做实验二时的第一个动作**：先在纸上列真值表、画电路图，再写 RTL。注意 `MuxKey` 的 `lut` 是拼出来的查找表，`{键, 数据}` 写反了不会报错、只会选错，写完一定要用手算真值表对一遍。
