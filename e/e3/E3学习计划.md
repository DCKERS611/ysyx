# E3 Linux 系统安装和基本使用：完整学习计划

## 1. 目标与时间原则

本计划对应“一生一芯”E3，目标是完成以下两部分：

1. Linux 基本使用：Shell、Shell 脚本、Vim、数据整理、命令行环境和 Git。
2. Linux 中的 C 语言进阶：完成《笨办法学 C》官方指定练习，并掌握 Makefile、库、测试、GDB、Sanitizer、Valgrind 和基础系统调用跟踪。

第一轮预计投入 **10～15 小时**。这只是阶段预算，不是删减内容的上限：

- 15 小时内没有完成的内容继续学习。
- 不以“看完视频”或“看懂代码”作为完成。
- 官方指定讲义、课后题和 C 练习最终必须全部完成。
- 长期型任务（例如持续使用 Vim）在集中学习结束后继续执行。

建议学习比例：

```text
阅读或视频：25%
亲手操作：60%
复盘和解释：15%
```

## 5. 每个 C 练习的完成标准

每个练习至少达到：

1. 已阅读：知道本练习要解决什么问题。
2. 已输入：代码真实存在于 WSL 文件中，不只停留在网页。
3. 已编译：开启常用警告，理解所有诊断。
4. 已运行：观察正常输入和至少一个边界情况。
5. 已解释：能说明关键数据、控制流和返回值。
6. 已扩展：完成教材附加题；开放式长期任务可标记“持续中”。
7. 已验证：按适用情况使用测试、GDB、Sanitizer、Valgrind 或 strace。

推荐的三类构建应分开，不把 ASan 和 Valgrind 混在同一个程序中运行：

```bash
# 严格调试构建
gcc -std=c11 -Wall -Wextra -Werror -g -O0 \
    source.c -o program

# Sanitizer 构建
gcc -std=c11 -Wall -Wextra -g -O0 \
    -fsanitize=address,undefined \
    source.c -o program_san

# Valgrind 构建（不带 ASan）
gcc -std=c11 -Wall -Wextra -g -O0 \
    source.c -o program_val

valgrind --leak-check=full \
         --show-leak-kinds=all \
         ./program_val
```
